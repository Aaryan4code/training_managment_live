# 🤖 AI-Powered Training Management System

> **A production-oriented web-based Training Management System**
> designed to manage courses, batches, trainers, students, sessions,
> assessments, submissions, feedback, certificates, and personalized

The system follows a **layered backend architecture** using **FastAPI**
and **PostgreSQL**, with a **Streamlit frontend** and **role-based
access control (RBAC)**.
